# Support

CAE OpenUSD Plugins is a development-stage project maintained by NVIDIA.

Use [GitHub Issues](https://github.com/NVIDIA-Omniverse/cae-openusd-plugins/issues)
to report bugs, request documentation, or suggest features. Reports are
reviewed on a best-effort basis; no response-time or resolution-time commitment
is provided.

Feature requests and other feedback may inform the project roadmap, but they do
not imply a commitment to implement a change. This project is currently not
accepting contributions.

Do not report security vulnerabilities through GitHub. Follow the private
disclosure process in [SECURITY.md](SECURITY.md).
