# Governance

CAE OpenUSD Plugins is maintained by NVIDIA. Repository maintainers appointed
through NVIDIA's GitHub organization controls make decisions about the project
roadmap, design, releases, and repository administration.

Users may report bugs and provide product feedback through GitHub Issues.
Maintainers decide whether and when reported work is scheduled. This project is
currently not accepting contributions.

See [SUPPORT.md](SUPPORT.md) for the support policy and
[SECURITY.md](SECURITY.md) for private vulnerability reporting.
